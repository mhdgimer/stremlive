# Facebook Live Telegram Bot

## Railway

1. ارفع هذه الملفات إلى GitHub.
2. اربط المستودع مع Railway.
3. أضف متغير البيئة:

BOT_TOKEN=توكن_بوت_Telegram

لا تضع Bot Token داخل GitHub.

## الأوامر

/start
يطلب Stream Key ثم رابط المصدر.

/live
يعرض حالة البثوث 1 إلى 5.

/stop 1
يوقف البث رقم 1.

يدعم المصدر الذي يمرره FFmpeg، مثل M3U8 وMPD وMP4 وروابط M3U/IPTV بحسب توافق المصدر مع FFmpeg.
